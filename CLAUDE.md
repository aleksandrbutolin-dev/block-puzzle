# Block Puzzle — первая игра (Яндекс Игры → RuStore)

Язык общения с разработчиком: **русский**. Разработчик — Александр, работает на MacBook (macOS), VS Code.

## Цель проекта

Первая игра в портфеле казуальных игр. Задача — выпустить на Яндекс Игры за 2–4 недели, проверить удержание и доход, затем развивать и портировать на Android (RuStore).

Стратегия направления: 5–8 игр за 3–6 месяцев, цель портфеля — 30–70 тыс. ₽/мес. Лучшие игры развивать (покупки, порт на Android).

## Почему block puzzle (итоги исследования рынка, сентябрь 2026)

- Казуальные головоломки — сегмент с лучшим сочетанием скачиваний и удержания.
- Бенчмарк удержания для puzzle: D1 ≈ 32%, D7 ≈ 12%, D30 ≈ 5%.
- Медиана рынка ниже: D1 ≈ 22%, D7 ≈ 4% (GameAnalytics, 2025).
- Block Blast! доказал, что жанр может жить только на рекламе, без покупок.
- Тренд — hybrid-casual: простая механика + мета-прогрессия. Без меты игроки уходят через пару дней.

## Площадки и деньги (для РФ)

- **Старт: Яндекс Игры (HTML5).** Реклама через РСЯ + покупки. Порог выплаты 3000 ₽. Доход с игры на рекламе ≈ 1 ₽ в день на активного игрока (ориентир из кейсов).
  - Риск: антифрод РСЯ может обнулить доход при бот-трафике — трафик только чистый.
- **Потом: RuStore (Android)**, комиссия 15%. Платёжный SDK RuStore с 01.02.2026 доступен только ИП/юрлицам. Реклама — Яндекс Реклама / VK Реклама.
- Google Play и App Store с российскими реквизитами не монетизируются — не целимся туда на старте.

## Геймдизайн

- **Механика:** поле 8×8, игроку даются 3 фигуры, перетаскиванием ставит их на поле; на место поставленной сразу приходит новая (в лотке всегда 3); заполненные строки/столбцы очищаются; игра заканчивается, когда ни одну фигуру некуда поставить.
- **Очки:** за блоки и линии, бонус за комбо (несколько линий сразу) и серии.
- **Мета-прогрессия (обязательно):** ежедневные задания, коллекция тем/скинов блоков, серия дней входа, рекорд.
- **Управление:** только тач/мышь, одна рука, портретная ориентация; должно работать и на ПК.
- **Визуальный стиль:** выбран — «мультяшное 3D», тёплый закат (подробности в «Решения и уроки»). Крупные изменения графики согласовывать с Александром.

## Монетизация (первая версия)

- Rewarded-реклама: «продолжить после проигрыша», «заменить фигуры».
- Межстраничная реклама между партиями, не чаще раза в 1–2 минуты.
- Покупки («отключить рекламу», скины) — добавлять после проверки удержания.

## Метрики и решения

| Результат | Решение |
|---|---|
| D1 < 20% | Игру не развиваем, делаем следующую |
| D1 25–30% | Дорабатываем онбординг и мету |
| D1 > 30% и D7 > 10% | Масштабируем: покупки, порт на Android |

Смотреть также время сессии и доход на игрока. A/B-тесты — через флаги Яндекс Игр.

## Технологии

- JavaScript + Phaser 3, сборка Vite.
- SDK Яндекс Игр: реклама, сохранения прогресса (облачные), лидерборд, язык.
- Локализация: русский и английский с первой версии.
- Архитектура модулями:
  - логика поля (без зависимостей от Phaser, покрыта тестами);
  - фигуры и генератор;
  - счёт;
  - мета-прогрессия;
  - реклама (обёртка над SDK с заглушкой для локального запуска);
  - UI-сцены.

## Структура

```
src/
  main.js        — создание Phaser.Game
  config.js      — общие константы (размер 720×1280)
  core/          — логика поля, фигуры, генератор, счёт. БЕЗ импорта Phaser. Тесты рядом: *.test.js
  meta/          — задания, скины, серия входов, рекорд
  platform/      — обёртка SDK Яндекс Игр (реклама, сохранения, лидерборд) + заглушка для локального запуска
  scenes/        — сцены Phaser (UI)
  i18n/          — тексты RU/EN
public/assets/   — картинки, звуки
```
